**版本**: v1.0

**设计总监**: DeepSeek

## 1. 设计理念

### 1.1 设计原则

| 原则 | 说明 | 应用场景 |
|------|------|----------|
| **简洁高效** | 去除冗余元素，聚焦核心功能 | 课程表展示、快速操作 |
| **信息清晰** | 层级分明，重点突出 | 课程卡片、详情页面 |
| **一致性** | 统一的设计语言和交互模式 | 全应用组件 |
| **可访问性** | 支持深色模式，考虑色觉障碍用户 | 色彩系统、对比度 |
| **情感化** | 营造专注、宁静的学习氛围 | 色彩、图标、动效 |

### 1.2 品牌调性

- **关键词**: 专注、高效、宁静、专业
- **视觉风格**: 现代简约、学术感、轻量级
- **目标感受**: 让用户专注于课程管理，减少干扰

## 2. 设计系统

### 2.1 色彩系统

#### 2.1.1 主色调

| 颜色 | 色值 | 使用场景 |
|------|------|----------|
| 主色 | `#4A6FA5` | 主要按钮、选中状态、品牌标识 |
| 辅色 | `#6B8E23` | 次要按钮、成功状态 |
| 强调色 | `#D35400` | 警告、重要提醒 |

#### 2.1.2 中性色

| 颜色 | 浅色模式 | 深色模式 | 使用场景 |
|------|----------|----------|----------|
| 背景色 | `#FFFFFF` | `#121212` | 页面背景 |
| 卡片背景 | `#F8F9FA` | `#1E1E1E` | 卡片、容器 |
| 分割线 | `#E9ECEF` | `#2D2D2D` | 列表分割线 |
| 次要文本 | `#6C757D` | `#A0A0A0` | 辅助信息 |
| 主要文本 | `#212529` | `#E0E0E0` | 主要内容 |

#### 2.1.3 课程颜色系统

为不同课程类型提供预设颜色，确保视觉区分度：

| 课程类型 | 颜色 | 使用场景 |
|----------|------|----------|
| 理论课 | `#4A6FA5` | 数学、物理等理论课程 |
| 实验课 | `#6B8E23` | 化学、生物实验 |
| 体育课 | `#D35400` | 体育、运动类课程 |
| 选修课 | `#8E44AD` | 选修、兴趣课程 |
| 会议 | `#16A085` | 会议、讲座 |
| 自习 | `#7F8C8D` | 自习、复习时间 |

### 2.2 字体系统

#### 2.2.1 字体家族

| 字体 | 使用场景 | 大小范围 |
|------|----------|----------|
| **Noto Sans SC** | 中文字体 | 12-24px |
| **Roboto** | 英文字体 | 12-24px |
| **SF Pro Display** | iOS 系统字体 | 12-24px |

#### 2.2.2 字号规范

| 层级 | 字号 | 字重 | 使用场景 |
|------|------|------|----------|
| H1 | 24px | Bold | 页面标题 |
| H2 | 20px | SemiBold | 模块标题 |

### 2.3 间距系统

基于 **8px** 网格系统：

| 间距 | 值 | 使用场景 |
|------|-----|----------|
| XS | 4px | 图标与文字间距 |
| S | 8px | 列表项间距 |
| M | 16px | 卡片内边距 |
| L | 24px | 模块间距 |
| XL | 32px | 页面边距 |
| XXL | 48px | 大模块间距 |

### 2.4 圆角系统

| 圆角 | 值 | 使用场景 |
|------|-----|----------|
| None | 0px | 分割线、输入框 |

| M | 8px | 标准卡片 |
| L | 12px | 对话框、大卡片 |

### 2.5 阴影系统

| 阴影 | 值 | 使用场景 |
|------|-----|----------|
| None | 无阴影 | 背景元素 |
| S | `0 1px 3px rgba(0,0,0,0.12)` | 卡片悬浮 |
| M | `0 4px 6px rgba(0,0,0,0.1)` | 对话框 |
| L | `0 10px 15px rgba(0,0,0,0.1)` | 模态框 |

## 8. 响应式设计

### 8.1 屏幕尺寸适配

| 设备类型 | 屏幕宽度 | 布局策略 |
|----------|----------|----------|
| 手机小屏 | < 360dp | 紧凑布局，减少边距 |
| 手机标准 | 360-420dp | 标准布局 |
| 手机大屏 | > 420dp | 宽松布局，增加信息密度 |
| 平板 | > 600dp | 多列布局，利用横向空间 |

### 8.2 横竖屏适配

#### 8.2.1 竖屏模式

- 周视图：7列网格，纵向滚动
- 日视图：时间轴在左侧，课程在右侧
- 详情页：单列布局，信息从上到下排列

#### 8.2.2 横屏模式

- 周视图：保持7列网格，增加节次显示数量
- 日视图：时间轴在上方，课程卡片网格排列
