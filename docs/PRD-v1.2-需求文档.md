# Sleepdown 课程表应用需求文档

**版本**: v1.2
**日期**: 2026-02-19
**状态**: 已评审

---

## 1. 项目背景

### 1.1 问题陈述
当前市面上主流的课程表应用都不够简洁易用，严重影响用户体验。用户每次打开应用都需要等待广告加载和跳过，违背了课程表应用"快速查看课表"的核心使用场景。

### 1.2 解决方案
开发一款无广告、轻量级、跨平台的课程表应用 **Sleepdown**（取自 Wake Up 的反义词），专注于提供纯粹、高效的课程表管理体验。

### 1.3 目标用户
- 在校大学生、研究生
- 需要管理课程表的学生群体
- 对广告敏感、追求简洁体验的用户

---

## 2. 产品概览

### 2.1 产品定位
一款轻量级、无广告、跨平台的智能课程表管理应用。

### 2.2 核心价值
- **无广告干扰**：纯粹的课表查看体验
- **智能导入**：多种方式一键导入课表
- **跨平台同步**：iOS / Android / 鸿蒙多端支持
- **高效触达**：桌面小组件，无需打开应用即可查看

### 2.3 技术选型
- **开发框架**: Flutter（实现 iOS、Android、鸿蒙跨平台）
- **UI 规范**: Material Design
- **存储**: SQLite 本地数据库

| 自定义节次数量 | 支持设置每天的课程节数 | P0 |

## 4. 非功能需求

### 4.1 性能要求
- 应用启动时间：< 1秒
- 页面切换流畅度：≥ 60fps
- 内存占用：< 100MB（前台运行时）

### 4.2 安全要求
- 用户数据本地加密存储
- 教务网站访问遵循目标站点协议
- 不收集用户隐私数据

### 4.3 可维护性
- 模块化架构设计
- 完善的日志系统（用户可选开启）
- 热更新配置支持（教务网站解析规则）

## 7. 附录

### 7.1 名词解释
- **节次**：每天课程的时间段划分，如第1-2节、第3-4节等
- **周次**：学期中的第几周，用于标识课程生效的时间范围
- **小组件**：桌面Widget，可在不打开应用的情况下显示课程信息

### 7.2 CSV 导入格式规范

CSV 格式同时用于**文件导入**和**复制粘贴导入**。

#### 格式定义

```csv
课程名称,星期,开始节数,结束节数,老师,地点,周数
高等数学,1,1,2,小明,逸夫楼201,1-5、7-11单、12-16双
线性代数,2,3,4,小红,理工楼110,1-16
大学英语,2,3,4,小红,文成楼125,2、5、8
```

#### 字段说明

| 字段 | 说明 | 取值范围 |
|------|------|----------|
| 课程名称 | 课程名称 | 任意文本 |
| 星期 | 星期几 | 1-7（周一至周日） |
| 开始节数 | 开始上课的节次 | 正整数 |
| 结束节数 | 结束上课的节次 | 正整数（≥开始节数） |
| 老师 | 授课教师 | 任意文本 |
| 地点 | 上课地点 | 任意文本 |
| 周数 | 上课周次 | 支持多种表达方式 |

#### 周数字段格式说明

周数字段支持灵活的表达方式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 单周次 | `5` | 仅第5周 |
| 连续周次 | `1-16` | 第1周到第16周 |
| 离散周次 | `2、5、8` | 第2、5、8周（使用中文顿号分隔） |
| 单周 | `1-16单` | 第1-16周的单周 |
| 双周 | `1-16双` | 第1-16周的双周 |
| 组合表达 | `1-5、7-11单、12-16双` | 支持多种格式组合 |

#### 使用场景

- **文件导入**：将课表保存为 `.csv` 文件后导入
- **复制粘贴导入**：直接复制 CSV 文本粘贴到应用中导入，应用识别前导词
